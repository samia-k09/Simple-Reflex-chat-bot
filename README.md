# Simple Reflex Chatbot

A web-based chatbot built using HTML, CSS, and JavaScript.

## Live Demo

https://simple-reflex-chat-bot.vercel.app

## Features

- Simple Reflex Agent logic
- Modern chatbot interface
- No backend or database
- No memory or stored conversation history
- Deployed using Vercel

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- Vercel
